# Maison Noor - Luxury Boutique Store

Premium multi-page boutique demo with worldwide checkout, built for GitHub Pages.

## Pages (13)
index.html (Home), shop.html, product.html, cart.html, checkout.html, wishlist.html, about.html, contact.html, faq.html, shipping.html, size.html, privacy.html, terms.html

## Features
- Search bar with live suggestions, category filters and sorting
- 8 products, quick add, wishlist, discount codes
- Currencies: USD, EUR, GBP, AED, PKR
- Payments: card, PayPal, Apple Pay / Google Pay, bank transfer, cash on delivery
- Help centre: FAQ, shipping and returns, size guide, privacy policy, terms
- Smart chat assistant and WhatsApp button
- Mobile-first design

## Files
style.css, app.js, site.js, bot.js, 13 .html pages and the 8 product photos (.jpg) in the same folder.

## Deploy
Settings > Pages > Deploy from branch > main > / (root).
